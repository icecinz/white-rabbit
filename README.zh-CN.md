# White Rabbit · 小白兔

[English](README.md) · [简体中文](README.zh-CN.md)

<img src="assets/icon.png" alt="小白兔" width="80">

**换 AI 时，让对话、资料和成果继续整理在一起。**

小白兔是一个本地 AI 工作入口，面向在同一项目中使用多个 AI 助手的人。找回旧对话，挑选要带上的前文和文件，选择保存好的 Agent 配置，再继续处理任务。希望少花时间找资料，少重复解释同一个项目。

这是一个**持续开发中的早期版本**，当前主要面向 macOS。应用界面目前以中文为主，入门文档提供中英文两版。

![使用虚构对话的小白兔演示界面](assets/demo.png)

*截图使用虚构对话；演示回复由本地规则生成，没有调用 AI 模型。*

## 现在有什么

- **对话资料库：**浏览、搜索已索引的原生历史，把相关工作分组，并保存 Markdown 引用和快照。
- **明确选择前文和材料：**先预览选中的消息与固定版本的文本文件，再交给另一个 Agent。图片是否可用取决于具体 Agent 和模型配置。
- **独立的 AI 与记忆配置：**分别选择保存好的 Agent／模型配置和记忆配置。
- **原生 Agent 连接：**实验性接入 Codex、Hermes、Pi、Claude Code、DeepSeek Harness，复用它们原有的执行和会话机制。
- **小白兔专员：**独立的 Codex 对话，通过与页面共用的有限业务接口，查看或修改已接通的设置。
- **可复用部件：**六个 Python 包分别提供内容、输入准备、记忆、原生运行基础、界面资源和专员核心。

## 先试演示

需要 **Python 3.11 或更新版本**。在终端运行：

```sh
git clone https://github.com/icecinz/white-rabbit.git
cd white-rabbit
python3 -B demo.py
```

打开 <http://127.0.0.1:17862/>。演示无需 API Key、模型或 Agent。如果端口已被使用，可以改用 `python3 -B demo.py --port 17863`。

可以沿着这条路径试用：

1. 搜索 `纸船`，找到包含编号 `7318` 的虚构旧对话。
2. 打开准备好的共同聊天，问“之前的代号是什么？”。
3. 切换模拟的 Codex、Hermes 配置，再问一次。
4. 从**更多 → 查看本轮上下文**检查本轮会带上哪些内容。

演示使用临时目录、虚构历史和明确标记的模拟回复，不读取原生 Agent 历史，也不调用模型。按 **Ctrl+C** 正常退出后删除本次演示数据；它不是日常聊天的保存模式。

## 接上真实 Agent

先选择一个你已经安装、配置好的 Agent。[原生连接指南](docs/native-agents.zh-CN.md)说明启动命令、依赖和当前限制。不显式提供启动参数时，原生连接保持关闭。

真实模式与演示不同：它可以读取本机原生历史、保存应用数据、启动所选 Agent，并沿用其账号或 API 配置。发送给在线模型的材料会经相应服务传输。本仓库不附带 Agent 完整程序、账号、订阅或可选服务。

## 当前边界

- 当前开发面向 **macOS／POSIX**，不支持 Windows；部分文件操作仅支持 macOS。
- 跨 Agent 交接的是明确选择的文字与兼容材料，不是另一家的完整内部运行状态。
- 原生连接仍在实验。工具、权限、恢复、图片和模型兼容性因路径而异，不承诺完整能力等价或零性能损耗。
- 尚未实现跨电脑任务调度、远程唤醒、云备份和 Markdown 正文自动同步。手机访问目前依赖外部 IM.codes 通路及在线的 Mac。
- 发送结果未知时查询原回执，不自动重复发送。
