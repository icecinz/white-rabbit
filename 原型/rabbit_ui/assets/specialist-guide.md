# 小白兔专员指南

## 常用指令

- “把界面改成深色。”
- “按名称找到‘项目讨论’，先不要发送消息。”
- “把这段对话放进已经建立的‘工作’分组。”
- “这段对话下一轮使用‘项目记忆’，保持只读。”
- “下一轮不附加小白兔长期记忆，当前聊天上文照常保留。”

打开已有对话后，可在左上说“把这段对话下一轮调到 Max”；这次指令会带上当前对象编号。新草稿、历史索引或管理页需说清对话或配置名。输入和发送不切走当前页面；点“小白兔专员”标题看完整对话与需要处理的确认。

## 设置 Agent

“新建一份叫‘日常聊天’的 AI 配置，使用我已接入的这个 Agent。”

“复制‘日常聊天’配置，命名为‘工作讨论’，其他参数保持。”

“这段对话下一轮用已保存的‘工作讨论’配置；先核对是否适用于这个 Agent。”

配置是参数组合，不是另一段原生会话。原生对话不能直接换成别的 Agent 并保留同一原生身份；需要时另建对话，再引用所需内容。

## 切换大模型

“先列出当前目标已核对到的模型和强度选项，不改设置。”

“把‘日常聊天’换成目录里我选的模型，强度用它支持的那一档。”

“只改这段对话下一轮的模型；其他配置和记忆选择保持。”

名称和档位以实际目录为准。不是每个 Agent 都能局部改模型或强度；不支持时先说明，不改全局默认来代替。目录候选不是调用成功的证明；“核对并更新”只在手动点击时进行。

记忆也可直接说：“使用‘项目记忆’，只读取”“先检查这份记忆配置的连接元数据，不读私人内容”。更换记忆不会清除已进入上文的内容。

发送或保存结果未知时，保留原编号核对；不重发、不换编号。出现原生权限确认时，由你核对后决定。
