# 第一次用小白兔

[English](getting-started.md) · [简体中文](getting-started.zh-CN.md) · [首页](../README.zh-CN.md)

小白兔已经可以下载源码安装，目前还没有 `.app`、`.dmg` 或双击即装的安装包。不懂编程的人，建议请能操作本机的 AI 帮忙完成安装和检查。

## 先准备这些

- **一台 Mac。** Windows 暂不支持；其他 POSIX 系统要手动运行，不走下面的常规安装。
- **Python 3.11 或更新版本。** 它负责运行小白兔，可以让安装助手检查并补装。手动安装可从 [Python 官网](https://www.python.org/downloads/macos/)下载，之后仍要核对版本和所选 AI 工具的依赖。
- **一个已经能用的 AI 工具。** Codex、Hermes、Pi、Claude Code、DSH 选一个就行。它需要先在本机装好，并完成登录或模型服务配置。小白兔本身不附带 AI 账号或模型。

这里的 Agent，指能在电脑上运行任务的 AI 工具。只有网页版账号，不一定已经具备本机连接条件。专员和额外记忆服务都可以以后再配。

## 请 AI 帮你安装

把下面这段话发给你平时使用、能读写本机文件和运行命令的 AI。只会网页聊天的工具无法完成本机安装。

> 帮我在这台 Mac 上安装小白兔：https://github.com/icecinz/white-rabbit 。请读仓库里的 AGENTS.md 和 docs/install-agent.zh-CN.md。先检查 Python，只连接一个我已经在用的 AI 工具，保留原来的账号、模型和服务配置。需要登录或确认时让我在本机完成。安装后打开页面，测试一次真实回答，刷新后在同一段对话里接着聊。最后告诉我以后怎么打开、数据在哪里、还有什么没配好，并帮我在桌面建立打开入口的替身。不要只启动演示版。

第一次不必设置所有功能。先让一个 AI 正常回答，能刷新后接着聊，就可以开始使用。若还没有任何可用的 AI 工具，需要先安装并配置其中一个；下载小白兔不会自动完成这一步。

## 想先下载文件

可以直接[下载源码 ZIP](https://github.com/icecinz/white-rabbit/archive/refs/heads/main.zip)。也可以打开[项目首页](https://github.com/icecinz/white-rabbit)，点绿色 **Code → Download ZIP**。

下载后双击解压，把文件夹放到一个准备长期保留的位置，例如“文稿”。通常解压后的文件夹叫 `white-rabbit-main`，里面能看到 `README.md`、`demo.py` 和 `原型`。

把这个文件夹的位置告诉安装助手，让它从这里安装。**解压只是拿到源码，还没有安装好。** 安装后也请保留这份文件夹，供查看文档和更新；不要把连接配置或密钥放进去。

熟悉命令行的人可以直接看[安装清单](install-agent.zh-CN.md)和[连接配置示例](native-agents.zh-CN.md#持久安装)。下载 ZIP 不需要先安装 Git。

## 装好以后怎么打开

如果安装助手已在桌面放好替身，双击它即可。程序生成的原始入口在一个隐藏文件夹中，可以这样找到：

1. 打开 **Finder（访达）**，按 **Command + Shift + G**。
2. 输入 `~/.imcodes/one-ai`，按回车。
3. 双击 **打开小白兔.command**，浏览器会打开本机页面。

这个入口会启动已安装的小白兔。只在服务已经运行时，直接访问 <http://127.0.0.1:17860/> 才能打开页面。

`.imcodes` 是沿用的目录名，不用另外安装 IM.codes。小白兔的程序和数据保存在这里；你原来使用的 AI 工具仍保留自己的资料。

## 怎么知道真的能用了

在小白兔里选刚接通的 AI，新建一段对话：

1. 发一句“请记住代号纸船7318，简短回答，不用工具”，等它真实回复。
2. 刷新页面，回到同一段对话，确认刚才的问答还在。
3. 再问“刚才的代号是什么？”，确认能接着回答。
4. 关闭页面，再用留下的打开入口进入，确认以后不必重新输入长命令。

登录后自动启动，需要在你自己的 Mac 上实际退出登录再登录后检查。刷新页面成功，只说明刷新后能继续，不能代替这一步。

## 卡住时先看这里

| 遇到的情况 | 接下来做什么 |
| --- | --- |
| 提示找不到 Python，或版本太旧 | 让安装助手找到或安装合适版本，并使用稳定的绝对路径 |
| 页面打开了，但不能发送 | 检查是否接通了真实 AI，以及原工具是否能正常登录和回答 |
| 回复带有“【模拟回答】”标记 | 这是本地规则演示。让安装助手按安装清单配置真实连接 |
| 提示端口已占用 | 先确认是不是已有小白兔；不要直接关闭未知服务或删除数据 |
| 登录、授权或原生审批在等待 | 由你在本机确认。不要把 Key、验证码或凭据文件发到聊天里 |
| 图片不能用 | 请安装助手检查服务 Python 的 Pillow 和所选 AI 的图片支持 |

提问题时，说明 Mac 系统版本、选择的 AI、做到哪一步，附错误文字即可。密钥、私人聊天和个人路径请先遮掉。
