# Roadmap · 近期路线

This is a direction of work, not a delivery schedule. A smaller feature that someone can run and explain is preferable to a long list of nominal integrations.

1. **Make the first useful path reproducible.** Keep the fictional demo easy to start, improve real-agent setup, and help another person find old project material and continue a concrete task.
2. **Improve the single-machine native experience.** Focus on conversation ownership, approvals, recovery, and clear errors. Keep each agent's execution loop and configuration intact.
3. **Make materials easier to carry forward.** Improve previews, version checks, Markdown organization, and explicit handoffs without implying full internal-state migration.
4. **Keep modules reusable.** Reduce remaining host coupling where a real reusable interface is clear; preserve transaction boundaries and avoid duplicate business rules.
5. **Improve public onboarding and language access.** Keep English and Chinese documentation aligned; application UI internationalization remains future work.

Cross-computer scheduling, remote wake-up, Windows support, cloud synchronization, and complete tool/performance equivalence are not current release promises. Add them only when there is a concrete use case and an independently verifiable path.

## 中文

1. 让别人能复现一条有用路径：找回项目资料，接着完成一个实际任务。
2. 打磨单机原生对话的归属、审批、恢复与错误提示，保留原执行器。
3. 改善材料预览、版本检查、Markdown 整理与明确交接。
4. 继续减少宿主耦合，同时保留必要的共同事务，不复制业务规则。
5. 保持中英文文档同步；界面国际化仍待后续实施。

跨电脑调度、远程唤醒、Windows、云同步和完整能力等价均没有当前版本的交付承诺。先完成少量可用、可解释、可验证的功能。
